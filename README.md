# ai_research_analyse
一、项目简介
本项目是基于 Python 实现的学术论文全流程数据分析工具，读取本地papers.csv论文原始数据集，完成数据清洗、多维度统计分析、图表可视化、MySQL 持久化存储整套流水线。
针对计算机顶会论文进行四大维度分析：历年论文产出数量、高校 / 科技企业机构产出对比、论文标题高频热词统计；所有清洗后原始数据与统计结果全部存入 MySQL 数据库，支持后续查询与二次分析。

二、技术栈
1. 编程语言
Python 3.8+
2. 数据处理库
pandas：CSV 读取、数据清洗、分组聚合、统计计算、数据入库
re：正则文本清洗、标题分词过滤
collections.Counter：热词频次统计
3. 可视化绘图
matplotlib：折线图、横向柱状图，支持中文显示、自定义分辨率、自动保存图片至本地文件夹
4. 数据库交互
MySQL 8.0：数据持久化存储
SQLAlchemy + pymysql：ORM 数据库连接，支持 utf8mb4 完整 emoji / 特殊字符兼容
5. 项目模块化
config.py：全局配置（数据库账号、停用词、图片分辨率）
utils.py：通用工具函数（机构分类、标题清洗分词）

三、项目目录结构

四、数据库说明
1. 数据库基础配置
数据库名：paper_analysis
字符集统一：utf8mb4（兼容特殊符号、生僻字符，解决中文 / 表情乱码报错）
连接账号：root / 密码 123777（可在 config.py 修改）
2. 自动生成四张数据表
papers_clean
清洗后的完整论文原始数据，去除机构为空、首尾空格无效行，存储所有论文基础信息
papers_year_count
按年份统计论文数量，索引自动存入数据库作为year年份字段，另一列为对应年份论文总数
papers_year_Affi
按年份 + 机构类型聚合统计表，区分大型科技企业、高校 / 科研院所、其他机构每年产出量
papers_top_words
论文标题 TOP20 高频热词表，包含热词文本、出现频次
